# 🧪 FreeCodeCamp Relational Database Projects

This repository contains five projects completed as part of the **Relational Database Certification** on freeCodeCamp. Each project demonstrates practical use of PostgreSQL, Bash scripting, and database design principles.

---

## 📂 Projects Included

### 🌌 1. Celestial Bodies Database

A PostgreSQL database modeling a universe with galaxies, stars, planets, and moons.

**Key Features:**

* Normalized relational schema
* Multiple related tables with foreign keys
* Complex relationships between celestial objects

**File:**

* `universe.sql`

---

### 🎯 2. Number Guessing Game

A Bash-based game where users guess a randomly generated number, with scores stored in a PostgreSQL database.

**Key Features:**

* User tracking system
* Best score recording
* Random number generation
* Database interaction via Bash

---

### ⚛️ 3. Periodic Table Database

A CLI tool that queries a PostgreSQL database to display information about chemical elements.

**Key Features:**

* Fully normalized database with multiple tables
* Bash script (`element.sh`) for querying
* Accepts atomic number, symbol, or name as input
* Clean and formatted output

**Files:**

* `element.sh`
* `periodic_table.sql`

---

### 💇 4. Salon Appointment Scheduler

A command-line appointment booking system using Bash and PostgreSQL.

**Key Features:**

* Service selection system
* Customer management
* Appointment scheduling
* Interactive CLI interface

---

### ⚽ 5. World Cup Database

A database that stores World Cup match results and team data.

**Key Features:**

* Data import from CSV
* Relational structure with teams and games
* SQL queries for analysis

---

## 🛠️ Technologies Used

* PostgreSQL
* Bash scripting
* Git & GitHub

---


## 📌 Notes

* All projects were completed following freeCodeCamp requirements.
* Databases are exported using `pg_dump` with `--inserts`.
* Scripts are designed to run in a Linux/bash environment.
